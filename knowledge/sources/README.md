# Proveniência das fontes

O [registro](registry.json) usa caminhos relativos a `knowledge`, conforme `path_base`. `sha256` identifica exatamente o artefato distribuído. No caso de extratos sanitizados, não é o hash do original. O campo `sha256_original_mixed` de I07 é uma referência histórica ao original misto, que não está neste pacote.

I01–I06 estão distribuídos. I07 distribui a matriz sanitizada; P01 distribui apenas o extrato de orientações em evidence-guidance. Nenhum desses extratos inclui o documento pessoal original. I08 (imagem 9box) e X02 (tabela histórica) são referências indisponíveis: identificá-las no registro não significa que foram inspecionadas ou validadas.

A verificação do pacote confere IDs, caminhos e hashes dos artefatos presentes e exige uma limitação explícita para referências ausentes. Isso verifica integridade/proveniência, não vigência ou validade institucional. Versão institucional e pendências continuam inalteradas. Novas fontes normativas dependem do fluxo de manutenção.
