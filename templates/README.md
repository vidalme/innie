# Modelos de trabalho

Exemplos são fictícios. Copiar para `pessoal/inbox`, preencher e revisar antes de propor. Eles não geram evidências por si só.

- `example-changes.json`: perfil, objetivo e ação sem datas presumidas. Exige ciclo ativo.
- `evidence-changes.json`: registro inicialmente relatado. Incluir source_ids reais após importar.
- `p2p.md`: pauta e decisões de alinhamento.
- `quarter-review.md`: revisão de marco parcial, com entregas e bloqueios.
- `institutional-review.md`: validação de regra antes de incorporá-la ao núcleo.

O calendário recebe datas concretas via ciclo/calendário; os marcos devem ser informados para cada ciclo. Não aplicar modelos sem adaptação.
